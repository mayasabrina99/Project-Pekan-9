# Project Pekan 9

Program Java sederhana yang menampilkan `Hello World`.

## Menjalankan di NetBeans

1. Pilih **File > Open Project**.
2. Buka folder `Project-Pekan-9`.
3. Buka `src/main/java/helloworld/HelloWorld.java`.
4. Klik kanan pada file, lalu pilih **Run File**.

Output:

```text
Hello World
```
